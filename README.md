# CanteenHub

## Project Description
CanteenHub is a web application that connects students with campus canteens, providing easy access to menus, orders, and feedback. The goal is to streamline the dining experience on campus by offering a user-friendly platform.

## Setup Instructions
1. **Clone the Repository**:
   ```bash
   git clone https://github.com/rahullramann0809/CanteenHub.git
   cd CanteenHub
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Start the Development Server**:
   ```bash
   npm start
   ```

4. **Access the Application**:
   Open your browser and navigate to `http://localhost:3000` to view the application.
